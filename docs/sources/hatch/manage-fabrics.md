# Manage fabrics

- **Source:** https://hatch.embroideryhelp.net/v3/en/OnlineHelp/Basics/customize_designs/Manage_fabrics.htm
- **Collected:** 2026-02-20

**Summary:** Create and edit custom auto fabric settings. Fabric Settings dialog sets values for four object groups – Tatami/Embossed Fill, Wide Satin, Narrow Satin, Lettering – and recommended stabilizers.

---

In addition to the predefined auto fabric settings, you can create custom fabric settings to suit particular needs. You can also modify, rename or delete any custom fabrics you create.

## To manage auto fabrics

1. Select Software Settings > Manage Auto Fabrics. Most of the time, you will come to this dialog in order to edit auto fabric settings or create fabric variants.
2. To create a variant, select the base fabric and click Create.
3. Enter a descriptive name.
4. Click OK. The Fabric Settings dialog opens. This dialog lets you set auto fabric values for four object groups – Tatami/Embossed Fill, Wide Satin, Narrow Satin, and Lettering – as well as details of any recommended stabilizers.
