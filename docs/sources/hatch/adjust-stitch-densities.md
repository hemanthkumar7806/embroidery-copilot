# Adjust stitch densities

- **Source:** https://hatch.embroideryhelp.net/v3/en/OnlineHelp/Basics/customize_designs/Adjust_stitch_densities.htm
- **Collected:** 2026-02-20

**Summary:** Use Customize Design / Edit Objects > Adjust Stitch Spacing to override density for selected objects; percentage adjustment (e.g. 200% to reduce density). For different fabric/thread or to reduce stitch count.

---

Use Customize Design / Edit Objects > Adjust Stitch Spacing to manually override stitch densities for selected objects.

You may need to change stitch density in order to stitch on a different fabric or with a different thread. Or you may want to do a test design and reduce the overall stitch count for efficient stitchout. Hatch Embroidery lets you change the density of most stitch types across the whole or selected parts of a design.

To override current settings for the entire design, press Ctrl+A to select everything. Open the dialog and set a percentage adjustment – e.g. 200% to increase stitch spacing and thereby reduce overall density. Check the revised stitch count in the Status Bar. [See also Object properties.](https://hatch.embroideryhelp.net/v3/en/OnlineHelp/Basics/customize_designs/Object_properties.htm#XREF_13962_Object_properties)
