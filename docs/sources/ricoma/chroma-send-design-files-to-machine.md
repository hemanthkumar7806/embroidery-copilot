# Why Can't I Send My Design Files to My Embroidery Machine to Chroma?

- **Source:** https://support.ricoma.com/hc/en-us/articles/4408634017555
- **Collected:** 2026-02-20

**Summary:** Troubleshooting wired and wireless transfer of designs from Chroma to the embroidery machine (IP, firewall, connection).

---

If you are experiencing issues with sending your designs from your Chroma digitizing software to your embroidery machine, there could be a problem with either your wired connection or wireless setup.

**Wired/Ethernet:** Check the physical connection; ensure the machine has an IP address (top of control panel next to Ricoma logo) and that it matches the IP for the machine in Chroma. Some computers cannot support a direct connection—plug the ethernet cable into the switch or router. Test the connection via Command Prompt (Windows) or Terminal (Mac): type "Ping" and your IP address. If you get no response, check firewall (Windows Defender, McAfee, Avast, etc.) or consult a network professional.

**Wireless:** Same IP match and ping test; adjust firewall or wireless settings if the connection fails. Ensure the machine is on the same network and the IP in Chroma matches the panel.
