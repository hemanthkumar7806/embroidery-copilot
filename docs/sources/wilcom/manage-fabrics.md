# Manage fabrics

- **Source:** https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/properties/Manage_fabrics.htm
- **Collected:** 2026-02-20

**Summary:** Create and edit custom fabric presets. Auto Fabric Settings define defaults for Tatami/Program Split (length, spacing, underlay, pull comp), Wide Satin, Narrow Satin (density slider), and Lettering, plus stabilizer notes.

---

In addition to predefined [fabric](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_fabric) settings, you can create your own custom fabrics to suit particular needs. You can also modify, rename or delete custom fabrics.

## To create a new fabric

1. Select Setup > Manage Auto Fabrics. If you already have custom fabrics defined, you have the option of editing, renaming, or deleting.
2. To create a new fabric type, click Create.
3. Enter a new fabric name. If you want to base the new fabric on [default settings](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_defaults), select blank.
4. Click OK.

The Auto Fabric Settings dialog opens. This dialog allows you to set the fabric values for four object groups – Tatami/Program Split, Wide Satin, Narrow Satin, and Lettering – as well as enter details of any recommended stabilizers.

## To set tatami/program split values

Click the tab to access Tatami/Program Split Fill settings. These will become the defaults for Tatami and Program Split objects.

- Adjust Length and Spacing settings for your Tatami / Program Split Fill objects as required. Tatami stitch consists of rows of run stitches and is suitable for filling large, irregular shapes. [See Tatami stitching for details.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/stitches/Tatami_stitching.htm#XREF_84758_Tatami_stitch) Program Split is a decorative stitch type for wide/large areas. [See Creating textures with program splits.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Decorative/patterns/Creating_textures_with_program_splits.htm#XREF_45143_Creating_textures)
- Set a suitable underlay type for Tatami/Program Split objects. [See Stabilizing with automatic underlay.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Quality/underlays/Stabilizing_with_automatic_underlay.htm#XREF_32080_Automatic_underlay)
- Set a pull compensation allowance. [See Compensating for fabric stretch.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Quality/underlays/Compensating_for_fabric_stretch.htm#XREF_43595_Pull_compensation)

## To set satin object values

- Click the tab to access Wide Satin settings (defaults for larger Satin objects). Adjust as for Tatami/Program Split. [See Satin stitching.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/stitches/Satin_stitching.htm#XREF_78440_Satin_stitching) Instead of Stitch Length and Stitch Spacing, you have a single **density setting** controlled by a slider bar.
- Click the tab for Narrow Satin and adjust similarly; narrow objects often need a different underlay type.

## To set lettering object values

Click the tab to access Lettering settings and adjust as for Satin objects. [See Applying stitch types & effects to lettering.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Lettering/lettering_advanced/Applying_stitch_types_effects_to_lettering.htm#XREF_73913_Applying_different)

## To set stabilizer settings

Click the tab to access Stabilizer settings. Key in one or more recommended stabilizer(s) with a description; this is shown in the Choose Fabric dialog. [See Change fabrics.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/properties/Change_fabrics.htm#XREF_31547_Changing_fabrics)
