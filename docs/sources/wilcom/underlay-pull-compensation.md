# Underlay & Pull Compensation

- **Source:** https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Quality/underlays/Underlay_Pull_Compensation.htm
- **Collected:** 2026-02-20

**Summary:** Overview of underlay and pull compensation in EmbroideryStudio: stitch spacing, pull compensation, and underlay must be correct for the cover stitch type, object type, shape, and fabric. Fabric settings (object properties) are available for the fabric you stitch on.

---

Embroidery stitches pull fabric inward where needles penetrate. This can cause [fabric](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_fabric) to pucker, [stitch bunching](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_stitch_bunching), and/or unsightly gaps to appear in the embroidery. EmbroideryStudio includes many techniques for achieving smooth, even placement of stitches, and the elimination of gaps in designs.

For an object to sew out correctly, it must have correct [stitch spacing](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_stitch_spacing), sufficient [pull compensation](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_pull_compensation), together with a suitable [underlay](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_underlay_stitch) for the particular combination of cover stitch type, object type, object shape, and fabric.

Note: EmbroideryStudio provides a set of optimized [fabric settings](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_fabric_settings) that take into account the type of fabric you are stitching on. These settings are all [object properties](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/glossary/glossary.htm#HT_properties), some of which are entirely automated and some which you have control over. [See Object Properties for details.](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/properties/Object_Properties.htm#XREF_24050_Properties_Fabrics)
