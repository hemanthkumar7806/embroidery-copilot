# Parameters - Fill

- **Source:** https://embird.com/studio/manual/3075par_fill.htm
- **Collected:** 2026-02-20

**Summary:** Fill object params: density (distance between rows; 4.0 = 0.2 mm), pull compensation; Plain Fill / Motifs / Auto Column; Edge and Zig-Zag underlays; gradient, effects.

---

These parameters apply only to Fill objects. The Fill object can be filled with stitches in one of three ways: (1) Plain Fill – parallel running stitches with Pattern; (2) Motifs; (3) Auto Column – filled like Column objects.

**Density** is distance between rows of stitches or motifs. Density 4.0 indicates that this distance will be 0.2 mm. Default value of density is derived from the Default Thread Weight in Preferences.

**Pull Compensation** is extension of each stitch on edge of object in order to compensate for thread pull (on elastic fabric) or sinkage (on fleece). The thread pull causes the ends of stitches to be pulled inwards and object is smaller (narrower) than intended.

## 1. Plain Fill Parameters

Pattern, Random Shift, Scale; Complete row if density above; Max. Random Broadening; Use jumps (if loose density).

**Plain Fill Underlays.** Edge and both Zig-Zag underlays can be usually turned on on all Plain Fill objects because Studio ignores these underlays on small objects. Turn them off if the fabric is firm and does not need the stabilization. Edge Walk Underlay helps to make crisp edges of fill. Zig-Zag Underlays parameters define the angles and densities; they stabilize the fabric with a grid of loose stitches before the higher density cover stitches.

## 2. Motif Parameters

Motif, Shift, Scale; Use jump stitches. Common with Plain: Make Cover Stitches (switch off cover or underlays), Gradient, Effect (Wave, Contour fill, Radial, Square, Rounded fill).

## 3. Auto Column Parameters

Use Pattern; Auto Select Column Underlay. **Center** – underlay along center (small or thin objects). **Edge** – along edge (medium/large objects). **Zig-Zag** – with edge for large or thick objects. Density for zig-zag underlay.
