# Parameters - Column

- **Source:** https://embird.com/studio/manual/3125par_cmn.htm
- **Collected:** 2026-02-20

**Summary:** Column (satin) params: density, pull compensation; Sample fill vs Strips fill; Center/Edge/Zig-Zag underlay; Auto Select Underlay; gradient, envelope, auto corners.

---

These parameters apply only to selected objects that are Column objects. Column objects can be filled with stitches in two different ways: (1) Strips fill – lines stitched along contours of the column; (2) Sample fill – various zig-zag samples.

## 1. Sample Fill

Sample is the zig-zag stitch pattern. **Density** defines the maximum distance between stitch samples (on a bend, distance on inner curve is lower). **Pull Compensation** extends each stitch on edge to compensate for thread pull (elastic fabric) or sinkage (fleece).

Envelope, Auto Corners, Make Cover Stitches, Auto Shortening, Perpendicular Stitches, Max. Random Broadening, Gradient.

**Auto Select Underlay** – switch off to choose underlay manually. **Center, Edge and Zig-Zag** check boxes choose which underlays will be used. **Density** parameter indicates the density of the zig-zag underlay.

## 2. Strips Fill

Strips fill the column from one side to the other with stitches along the column edges. Number (of strips); Min. Length and Max. Length of stitches.
