# Parameters - Whole Design

- **Source:** https://embird.com/studio/manual/3025par_whole.htm
- **Collected:** 2026-02-20

**Summary:** Global parameters: Additional Density (whole design for different thread), Additional Pull Compensation (whole design for elastic/fleece); underlay offset (Edge, Zig-Zag) in mm or %; tie-up stitches; min/max underlay length.

---

These parameters are organized into several tabs:

## Main Tab

- **Minimum Stitch Length:** Global parameter (unlike maximum length of stitches, which can be adjusted separately for each object).
- **Columns Start/End Gap:** Size of the small gap at beginning and end of column-like objects. Prevents thread bulging at ends of columns.
- **Fills Start/End Gap:** Prevents thread bulging at ends of fill; especially important if there is a thin running stitch outline around the fill object.
- **Additional Density:** Adjust whole design at once for sewing with different types of thread. If the whole design seems too loose or too dense because of the threads used, adjust the density with this parameter.
- **Additional Pull Compensation:** Adjust whole design at once for sewing on different types of fabric. If the fabric is too elastic or if the design sinks into the fabric, use this parameter to add more pull compensation to the whole design at once.
- Comment, Reference Width, Reference Height (for user defined Border Samples).
- Combine Arranged Outline Parts – when Arrange Outline Parts is used, combine outline elements into larger segments or preserve for easier editing.

## Tie-Up Stitches Tab

Fill, Outline, and Column Tie-Up Stitches (small stitches before/after jump stitches); Tie-Up Stitches Length (maximum length).

## Offset Tab

Global offset affects distance of edge and zig-zag underlay of all objects. Two modes: (1) Absolute offset in mm, with optional % scale for elastic/fleece; (2) Constant distance in mm for all. **Offset of Edge Underlay** and **Offset of Zig-Zag Underlay** (separate offset available for fills, columns, appliques).

## Length Tab

Minimum and maximum length of fill and column underlay.
