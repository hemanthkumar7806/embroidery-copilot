# embroidery-ext

Embroidery design assistant: Inkscape MCP integration, rule/decision engine, and backend API.

## Structure

- `src/` — TypeScript rule engine and decision engine
- `BE/` — FastAPI backend
- `inkscape-mcps/` — Inkscape MCP server
- `inkspace-AI/` — Inkscape AI bridge extension
- `docs/` — Project documentation

## Quick start

```bash
npm install
npm test
npm run build
```

See `BE/README.md` and `docs/README.md` for backend and MCP setup.
